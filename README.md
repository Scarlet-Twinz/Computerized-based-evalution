# JPTS Grade Evaluation System

A browser-based academic grade evaluation interface built for JPTS Institute. The project provides a multi-page frontend for presenting grade and academic information through role-specific dashboards.

## Overview

The application is built primarily with HTML, CSS, and JavaScript, with Bootstrap, Font Awesome, and Google Fonts used in the frontend. The repository contains separate pages for the main application, authentication, student views, lecturer views, HOD views, exam-officer views, and an admin dashboard.

## Included Interfaces

- Main landing page
- Login page
- Student dashboard
- Lecturer dashboard
- Head of Department (HOD) dashboard
- Exam Officer dashboard
- Admin dashboard
- Application interface (`app.html`)

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Font Awesome
- Google Fonts

## Running Locally

Clone the repository:

```bash
git clone https://github.com/Scarlet-Twinz/Computerized-based-evalution.git
cd Computerized-based-evalution
```

Open `index.html` in a modern browser. For a more consistent local development experience, serve the repository with a simple static HTTP server.

No package installation is required for the frontend files currently included in the repository.

## Project Status

This repository is a frontend-focused academic evaluation project. The README intentionally documents the interfaces and technologies present in the repository without claiming a production backend or hosted service.
